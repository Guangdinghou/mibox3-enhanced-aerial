# 故障排查

## 重启后 ADB 消失

等待首页出现，在开发者选项中把 USB/ADB 调试关闭再打开，重新插接数据线并允许授权。不要在启动动画期间反复操作。

## Aerial 守护突然关闭

Android 5.1 会在强制停止应用时移除无障碍服务。完成布局写入后重新运行配置脚本，后续不要再强制停止 Aerial。

## Home 黑屏或无法返回

保持 USB ADB，立即运行 `scripts/59-restore-launchers.sh`。该脚本重新启用 `com.mitv.tvhome`，关闭 Aerial 守护并打开原厂首页。

## 安装长时间无输出

查看电视是否出现小米的 ADB 安装确认弹窗。只允许来源与哈希均已核对的 APK。

## ROOT 验证失败

停止，不要重复写入。保存完整输出，确认 SELinux、分区映射、SuperSU 组件版本和原始备份；无法解释时按恢复文档处理。

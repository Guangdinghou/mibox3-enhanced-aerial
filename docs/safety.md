# 安全说明

## 主要风险

- 永久 ROOT 会修改系统分区和启动逻辑，操作错误可能无法启动。
- 用户级卸载通常可恢复，但恢复依赖操作前保存的原始 APK。
- 停用原厂桌面前，必须确认 Aerial 已安装、能启动并声明 HOME。
- ADB 重启后可能失联；不要在没有 USB 物理访问条件时执行高风险步骤。

## 强制规则

1. 先运行设备检查和备份验证。
2. 一次只运行一个阶段；读完输出再继续。
3. 不跳过型号、SDK、芯片、分区及哈希校验。
4. 不提交或分享备份、镜像、ADB 密钥和设备唯一标识。
5. 无法解释错误时停止，不重复尝试写入。

## 第三方资源

只从 `sources.lock` 指定来源下载固定版本。哈希不匹配意味着文件不可使用，而不是更新校验值迁就文件。

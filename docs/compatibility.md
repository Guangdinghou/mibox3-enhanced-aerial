# 兼容性

## 已验证目标

| 项目 | 值 |
|---|---|
| 产品型号 | MiBOX3_PRO |
| 零售型号 | 小米盒子 3 增强版 MDZ-18-AA |
| 系统 | Android 5.1，SDK 22 |
| 平台 | MediaTek MT8173 系列 |
| 桌面 | Aerial v1.47 标准版 |

固件构建号可能存在小版本差异，因此永久 ROOT 前仍须核对分区、挂载和启动脚本。任何一项不匹配都不代表“基本兼容”。

## 明确不支持

- 小米盒子 3、3S、国际版 Mi Box 或其他相似命名设备。
- Android 版本、SDK 或分区布局不同的固件。
- 无法稳定使用 USB ADB、没有完整备份或无法恢复的设备。
